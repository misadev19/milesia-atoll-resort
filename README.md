# Milesia Atoll Resort

A luxury Maldives resort landing page with immersive visuals, smooth transitions, and scroll-based animations.

## Overview

Milesia Atoll Resort is a fictional luxury resort website created as a front-end design and development project.

The site is designed to create an immersive resort experience inspired by the atmosphere of the Maldives, combining large-scale imagery, elegant typography, smooth transitions, and scroll-triggered animations.

## Features

- Full-screen hero section
- Responsive design for desktop and mobile
- Smooth scrolling experience
- Scroll-triggered animations
- Image transitions and visual effects
- Mobile-friendly layout
- Interactive navigation

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger

## Purpose

This project was created as a portfolio sample to demonstrate front-end development, responsive web design, animation implementation, and attention to visual detail.
